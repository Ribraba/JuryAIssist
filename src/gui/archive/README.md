Ce dossier contient les anciennes versions de l'interface graphique, conservées pour référence historique.

### `main_window_OLD.py`
**Date:** 2026-01-03
**Description:** Première version de l'interface graphique avec layout traditionnel.

**Caractéristiques:**
- Barre de menu classique
- Layout vertical simple
- Panneaux de transcription et d'édition
- Contrôles audio basiques

### `main_window_OLD2.py`
**Date:** 2026-01-07
**Description:** Version intermédiaire avant l'intégration complète du design Figma.

**Caractéristiques:**

- Support de la pédale Olympus RS-31
- Timeline avec transcription
- Contrôles audio avancés (volume, vitesse)
